# Genre Playbook

Starting points, not formulas. Each entry gives a style-box template, a working BPM range, and slider bands. Swap in the specifics of the actual track — a template used verbatim produces a template-sounding song.

## How to use these

Each template follows the standard shape: `[Vocal identity]. [Genre + instrumentation]. [Production]`. Replace the vocal block first — it's the highest-leverage part and the one most likely to be wrong for a given track.

Then check three things:
1. Does every descriptor still add distinct information after your edits?
2. Is the genre block still at 2–3 descriptors?
3. Does the BPM match what the arrangement actually wants?

## Genre entries

### Pop / dance pop
`120–128 BPM` · W `0.10–0.30` · SI `0.60–0.80`
```
Confident female vocal, bright mid-range, layered harmonies on the hook.
Dance pop, punchy drums, bright synths, sub bass. Radio-ready polish,
wide stereo, vocal upfront.
```

### Indie / alternative
`95–115 BPM` · W `0.25–0.45` · SI `0.55–0.75`
```
Male tenor, warm, slightly raspy, conversational delivery. Indie pop,
jangly guitars, warm analog synths, live-feel drums. Vintage aesthetic,
tape saturation, roomy mix.
```

### Ballad / emotional
`60–76 BPM` · W `0.10–0.25` · SI `0.60–0.80`
```
Male baritone, gentle vibrato, close-mic intimacy. Piano ballad,
fingerpicked guitar, subtle strings entering at the bridge.
Sparse arrangement, natural dynamics, no compression glue.
```

### Hip-hop / lo-fi
`80–95 BPM` · W `0.20–0.40` · SI `0.50–0.70`
```
Male vocal, conversational flow, laid-back behind the beat. Lo-fi
hip-hop, jazz-sampled drums, upright bass, dusty Rhodes. Warm vinyl
crackle, tape hiss, underground aesthetic.
```

### Trap
`130–150 BPM (half-time feel)` · W `0.25–0.45` · SI `0.55–0.75`
```
Male vocal, auto-tuned, melodic ad-libs. Dark trap, 808 bass, crisp
hi-hat rolls, sparse minor-key keys. Atmospheric, heavy low end.
```

### Electronic / progressive trance
`134–142 BPM` · W `0.30–0.55` · SI `0.45–0.65`
```
Progressive trance, dark and hypnotic, metallic synth stabs, driving
bassline, ethereal pads. Building intensity, wide cinematic arrangement.
```
*(Instrumental — no vocal block. Add `Female vocal, airy, wordless` if a topline is wanted.)*

### House / afro house
`120–126 BPM` · W `0.30–0.50` · SI `0.50–0.70`
```
Afro house, organic percussion, deep sub bass, filtered chords,
marimba accents. Hypnotic groove, spacious mix, long builds.
```

### IDM / ambient electronic
`70–110 BPM or free` · W `0.55–0.85` · SI `0.25–0.50`
```
IDM, glitchy broken beats, granular textures, detuned analog pads,
processed field recordings. Lo-fi digital artifacts, unstable timing,
deep stereo field.
```

### Rock / alternative rock
`110–140 BPM` · W `0.20–0.45` · SI `0.55–0.75`
```
Male vocal, gravelly, powerful chest voice. Alternative rock, distorted
guitars, driving drums, thick bass. Stadium-sized production, anthemic
chorus, live room ambience.
```

### Punk
`160–200 BPM` · W `0.20–0.40` · SI `0.60–0.80`
```
Male vocal, snotty, shouted, slightly off-pitch. Skate punk, fast
downstroke guitars, blast-fast drums, no frills. Raw production,
minimal overdubs.
```

### Metal
`100–180 BPM` · W `0.10–0.30` · SI `0.65–0.85`
```
Male vocal, guttural growls with clean-sung chorus. Melodic death metal,
tremolo-picked guitars, double bass drums, harmonized leads.
Dense, dark, aggressive mix.
```
*Suno is weakest here. Lock hard on-genre and test V4.5 alongside V5 if output sounds thin.*

### Folk / acoustic
`70–100 BPM` · W `0.10–0.30` · SI `0.60–0.80`
```
Female alto, close and unforced, minimal vibrato. Reflective folk,
fingerpicked acoustic guitar, gentle brushed percussion, harmonica.
Intimate acoustic production, natural room, no drums.
```

### R&B / soul
`85–100 BPM` · W `0.20–0.40` · SI `0.55–0.75`
```
Female alto, sultry, breathy, R&B phrasing with subtle runs. Neo-soul,
warm electric bass, Rhodes, muted guitar. Polished contemporary mix,
vocal ad-libs layered wide.
```

### Jazz
`90–160 BPM (swing)` · W `0.40–0.65` · SI `0.40–0.60`
```
Female vocal, smoky, behind the beat, melismatic phrasing. Vocal jazz,
brushed drums, upright bass, comping piano, muted trumpet. Live club
ambience, minimal editing.
```

### Cinematic / orchestral
`60–120 BPM` · W `0.15–0.40` · SI `0.55–0.75`
```
Cinematic orchestral, low strings ostinato, solo cello, brass swells,
taiko hits. Wide hall reverb, slow dynamic build, no percussion until 1:30.
```
*(Instrumental. Section count is the main duration lever — see the duration table in SKILL.md.)*

### K-pop
`120–140 dance / 60–80 ballad` · W `0.20–0.40` · SI `0.65–0.85`
```
Mixed group vocals, layered harmonies, K-pop idol group. Girl crush
concept, maximalist production, dynamic shifts, genre-fluid.
Glossy modern mix.
```
See the genre-specific notes below — K-pop has the most structural requirements of any entry here.

### Country / americana
`75–130 BPM` · W `0.15–0.35` · SI `0.60–0.80`
```
Male baritone, weathered, storytelling drawl. Americana, pedal steel,
acoustic and clean electric guitar, brushed kit. Warm analog production,
vocal front and center.
```

### Reggae / dub
`70–90 BPM` · W `0.25–0.50` · SI `0.50–0.70`
```
Male vocal, laid-back patois-inflected phrasing. Roots reggae, one-drop
drums, heavy bassline, skanking guitar, melodica. Dub production,
tape delay throws, deep low end.
```

## Genre-specific notes

### Hip-hop / rap
Name the subgenre — boom bap, trap, lo-fi, drill, nerdcore. Specify the beat style: 808s, sampled drums, crispy snares. Describe flow explicitly if it matters. Rap sections get `[Rap Verse]`, not `[Verse]`. Lyric budget runs higher here — up to ~500 words.

### Electronic
BPM is critical, not optional. Name specific subgenres and synth types (analog, digital, chiptune, FM). Most electronic tracks are instrumental — drop the vocal block entirely rather than leaving a vague one.

### Punk
Tempo does most of the work. Vocal style is the other half — snotty, shouted, melodic, or gang-chanted are meaningfully different results.

### Folk / acoustic
Name the playing technique, not just the instrument: fingerpicking, clawhammer banjo, mandolin tremolo. Describe intimacy level explicitly; "acoustic" alone drifts toward polished singer-songwriter.

### K-pop
The hardest genre to get right, because it needs four things at once:

**Group vocal sound.** `mixed group vocals` is the single most important tag. Add `layered harmonies`, `gang vocals`, `group chant` for chorus density. Use `[All]` or `[Group]` before chant sections.

**Concept type.** Name it: girl crush, cute concept, dark concept, retro disco. This shapes more than "K-pop" alone does.

**Mid-song switch-up.** Genre changes between sections need per-section parenthetical cues in the lyrics box, not just a global style prompt — one of the two legitimate uses of parentheses there. Add `genre-fluid`, `dynamic shifts`, `maximalist K-pop production` to the style box.

**Code-switching.** Romanized Korean with hyphens (`Sa-rang-hae`) beats native script for pronunciation control. Keep English hooks and Korean verses as separate sections. Add `[Clear Vocals]` when mixing languages.

Common failures: sounds like generic pop (add `maximalist` + `glossy` + concept keywords); solo voice instead of group (add the group tags); rap verse sounds sung (use `[Rap Verse]` with an aggressive-flow cue); dance break has singing (keep its lyrics empty).

### Metal and heavy genres
Suno's weakest area. Lock Style Influence high, keep Weirdness low, and be specific about subgenre and vocal type (growls, screams, cleans, or a mix). Test V4.5 against V5 — for heavy material V4.5 sometimes wins outright.
